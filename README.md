# xxfilehost

**xxfilehost** — это легкий и быстрый локальный сервер для обмена файлами. 
Забудьте про провода и флешки: передавайте файлы с телефона на компьютер (и обратно) по обычному Wi-Fi через браузер.

## 📖 Зачем это нужно?
Программа создает мини-сайт на вашем ПК. Вы заходите на него с телефона, и можете:
* Скачивать файлы с ПК на телефон (фото, музыка, видео, документы).
* Загружать файлы с телефона на ПК.
* Переименовывать и удалять файлы прямо из браузера телефона.

## 🚀 Как пользоваться (Инструкция)

1. Запустите программу `xxfilehost` (через `.jar` или ярлык).
2. На экране компьютера появится окошко с адресом (например: `http://192.168.1.10:8080`).
3. Подключите телефон к **той же Wi-Fi сети**, что и компьютер.
4. Откройте любой браузер на телефоне (Chrome, Safari и т.д.) и введите этот адрес.
5. Готово! Вы увидите список файлов на ПК. Чтобы загрузить файл на ПК, нажмите «Выбрать файл» и «Upload to PC».

## ⚙️ Что нужно для работы?
* Установленная **Java** (версия 8 или выше).
* Компьютер и телефон должны быть подключены к **одному роутеру (Wi-Fi)**.

## 🛠️ Решение базовых проблем (FAQ)

**1. Телефон пишет: «Не удается получить доступ к сайту» или «Сайт недоступен»**
* **Причина:** Телефон и ПК в разных сетях, либо брандмауэр Windows блокирует соединение.
* **Решение:** 
  * Убедитесь, что телефон подключен именно к Wi-Fi, а не к мобильному интернету (4G/5G).
  * При первом запуске Windows может спросить разрешение на доступ к сети для Java. Нажмите **«Разрешить доступ»** (обязательно для «Частных сетей»).
  * Если окно не появилось, зайдите в «Брандмауэр Защитника Windows» -> «Разрешить взаимодействие с приложением» и найдите там `Java(TM) Platform SE binary`, поставив галочки.

**2. IP-адрес в программе изменился**
* **Причина:** Роутер выдает новый IP-адрес компьютеру после перезагрузки.
* **Решение:** Просто введите новый адрес, который показан в окошке программы. Либо настройте статический IP-адрес в настройках роутера (DHCP Reservation).

**3. Файл сохранился с неправильным расширением (например, .bin) или странным именем**
* **Причина:** Современные мобильные браузеры (Android) из соображений безопасности часто скрывают оригинальное имя файла и передают только «сырые» данные.
* **Решение:** Программа пытается определить формат сама, но если не получилось — файл сохраняется как `.bin`. Откройте сайт на телефоне, найдите этот файл и нажмите кнопку **Rename** (Переименовать), чтобы дать ему правильное имя и расширение.

**4. Программа не запускается (ошибка JVM not found)**
* **Причина:** На компьютере не установлена Java.
* **Решение:** Скачайте и установите бесплатную Java (JRE) с официального сайта `java.com`.

## 🇬🇧 English description

**xxfilehost** is a lightweight local HTTP server for fast file sharing between your PC and smartphone over Wi-Fi. No cables, no cloud, no accounts.

**How to use:**
1. Run `xxfilehost.jar`.
2. Enter the IP address shown in the app window into your phone's browser (make sure both devices are on the same Wi-Fi network).
3. Download or upload files directly through the web interface.

**Features:**
* Drag & drop style file uploads.
* Built-in file manager (Rename / Delete).
* Support for Cyrillic file names.
* Lightweight UI optimized for mobile screens.

**Troubleshooting:**
* If your phone can't connect, check your PC's Firewall settings and ensure both devices are on the same subnet.
* If the file has the wrong extension, use the "Rename" button on the web page.
